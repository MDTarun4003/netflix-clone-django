# Netflix Clone (Django)

## Overview
A full-stack Netflix clone built using Django with authentication, video streaming, and personalized features.

## Features
- User Authentication (Login/Signup)
- Movie Streaming
- Genre Filtering
- Search Functionality
- Watchlist (My List)
- Recommendation System

## Tech Stack
- Backend: Django
- Frontend: HTML, CSS, Bootstrap
- Database: SQLite

## Setup Instructions
1. Clone repo
2. Create virtual environment
3. Install requirements
4. Run server
